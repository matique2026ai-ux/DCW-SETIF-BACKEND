# 🛠️ DCW-SETIF-BACKEND — الخادم الخلفي لمنصة الرقابة والتفتيش
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف

واجهة برمجة التطبيقات (RESTful API) المتكاملة لتغذية منصة المتابعة والتفتيش الميداني، مع دعم كامل للتحكم في الصلاحيات والمصادقة الآمنة وإدارة الموظفين وقواعد البيانات المزدوجة.

---

## 🌐 روابط السيرفر والإنتاج (Live Production Server)

* **رابط السيرفر الأساسي (Render Cloud):** `https://drh-setif-api.onrender.com/api`
* **المسارات الرئيسية:**
  * `POST /api/auth/login` — تسجيل الدخول والحصول على JWT Token
  * `POST /api/auth/change-password` — تغيير كلمة المرور
  * `GET  /api/auth/users` — استعراض كافة المستخدمين (صلاحية Admin)
  * `POST /api/auth/users` — إنشاء مستخدم جديد
  * `POST /api/auth/generate-accounts` — توليد حسابات الموظفين تلقائياً
  * `GET  /api/dashboard/stats` — إحصائيات لوحة قيادة المدير الولائي والمحجوزات
  * `GET  /api/dashboard/recent-activity` — النشاطات الأخيرة لفرق التفتيش
  * `POST /api/attendance/check-in` — تسجيل الحضور اليومي
  * `POST /api/attendance/check-out` — تسجيل الانصراف
  * `GET  /api/programs` — استعراض البرامج الرقابية والمهام
  * `POST /api/programs` — إنشاء أمر مهمة جديد (رئيس المصلحة)
  * `POST /api/visits` — تسجيل وتوثيق زيارة ومعاينة ميدانية (المخالفات، الإجراء القانوني، قيمة المحجوزات)
  * `POST /api/visits/:id/approve` — تأشير واعتماد تقرير المعاينة رسمياً
  * `GET  /api/employees` — استعراض بيانات الموظفين (267 موظفاً)

---

## 🔒 نظام الصلاحيات والأمان (RBAC & Security)

1. **المدير الولائي (`director`):** وصول كامل للإحصائيات، الخريطة، والتقارير.
2. **رئيس المصلحة (`head_of_department`):** إدارة برامج المصلحة وتأشير المعاينات.
3. **رئيس المكتب (`bureau_chief`):** متابعة الأعوان والمفتشين الميدانيين.
4. **المفتش / العون (`inspector`):** تسجيل الحضور ومباشرة المهام والمعاينات.
5. **المسؤول التقني (`admin`):** إدارة المستخدمين وقواعد البيانات والصلاحيات.
