# 🛠️ DCW-SETIF-BACKEND — الخادم الخلفي لمنصة الرقابة والتفتيش
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف

واجهة برمجة التطبيقات (RESTful API) المتكاملة لتغذية منصة المتابعة والتفتيش الميداني، مع دعم كامل للتحكم في الصلاحيات ومسار الاستفسارات الإدارية، احتساب التأخر وفق قانون الوظيفة العمومية (الأمر 06-03)، والبصمة الجغرافية الذكية.

---

## 🌐 روابط السيرفر والإنتاج (Live Production Server)

* **رابط تطبيق الويب المباشر (Render Static Site):** [https://dcw-setif-tracker.onrender.com](https://dcw-setif-tracker.onrender.com)
* **رابط السيرفر الأساسي وقاعدة البيانات (Render API):** `https://drh-setif-api.onrender.com/api`
* **المسارات الرئيسية:**
  * `POST /api/auth/login` — تسجيل الدخول والحصول على JWT Token
  * `POST /api/auth/change-password` — تغيير كلمة المرور
  * `GET  /api/auth/users` — استعراض كافة المستخدمين (صلاحية Admin)
  * `POST /api/auth/generate-accounts` — توليد حسابات الموظفين تلقائياً
  * `GET  /api/settings` — استرجاع إعدادات النظام (فترة التسامح الصباحية)
  * `POST /api/settings` — تحديث إعدادات النظام وفترة التسامح (المدير والآدمن)
  * `GET  /api/attendance/delays-summary` — ملخص التأخرات المتراكمة ومقترحات الخصم القانونية
  * `GET  /api/inquiries` — استعراض ملفات الاستفسارات الإدارية
  * `POST /api/inquiries` — إصدار استفسار كتابي رسمي لموظف
  * `POST /api/inquiries/:id/reply` — إرسال رد وتبريرات المفتش
  * `POST /api/inquiries/:id/director-decision` — تسجيل القرار السيادي للمدير (قبول/تنبيه/خصم)
  * `POST /api/inquiries/:id/execute-deduction` — تنفيذ الخصم على الراتب من مكتب المستخدمين
  * `GET  /api/dashboard/stats` — إحصائيات لوحة قيادة المدير الولائي والمحجوزات
  * `GET  /api/dashboard/map-data` — بيانات التموضع الجغرافي الحي لفرق التفتيش
  * `POST /api/attendance/check-in` — تسجيل الحضور اليومي الذكي
  * `POST /api/attendance/check-out` — تسجيل الانصراف الميداني
  * `GET  /api/programs` — استعراض البرامج الرقابية والمهام
  * `POST /api/programs` — إنشاء أمر مهمة جديد (رئيس المصلحة)
  * `POST /api/visits` — تسجيل وتوثيق زيارة ومعاينة ميدانية (المخالفات، الإجراء القانوني، قيمة المحجوزات)
  * `POST /api/visits/:id/approve` — تأشير واعتماد تقرير المعاينة رسمياً
  * `GET  /api/employees` — استعراض بيانات الموظفين (267 موظفاً)

## 🔒 نظام الصلاحيات والأمان (RBAC & Security)

1. **المدير الولائي (`director`):** الآمر بالصرف، الفصل في الاستفسارات والخصومات، ضبط فترة التسامح الصباحية، والاطلاع على الخريطة والتقارير.
2. **رئيس المصلحة (`head_of_department`):** إنشاء أوامر المهمة، توجيه المفتشين، واعتماد تقارير المعاينات.
3. **رئيس مكتب المستخدمين (`bureau_chief`):** متابعة ساعات التأخر التراكمية، توجيه الاستفسارات، وتنفيذ قرارات الخصم على الرواتب.
4. **المفتش / العون (`inspector`):** تسجيل الحضور الذكي، الرد على الاستفسارات، ومباشرة المهام وتوثيق المعاينات.
5. **المسؤول التقني (`admin`):** إدارة المستخدمين وقواعد البيانات وضبط إعدادات فترة التسامح.
